# 🍷 Terassa Restaurant Bot

Telegram бот для ресторана с Mini App.

## Установка

1. Клонируй репозиторий
2. Установи зависимости: `pip install -r requirements.txt`
3. Заполни `.env` файл
4. Запусти: `python bot.py`

## Команды

- `/start` - Открыть меню
- `/orders` - Просмотр заказов (админ)
- `/upload` - Загрузить картинку (админ)
- `/add_dish` - Добавить блюдо (админ)
- `/help` - Помощь

## Структура

- `bot.py` - Основной бот
- `database.py` - Работа с БД
- `config.py` - Настройки
- `menu_data.py` - Меню
- `admin_upload.py` - Загрузка картинок

## Для администратора

Заказы приходят автоматически в чат. Можно менять статусы кнопками.

## Загрузка картинок

1. `/upload` - выбрать блюдо
2. Отправить фото
3. Готово!

## Mini App

Mini App должен быть развернут отдельно и указан в WEBAPP_URL.
